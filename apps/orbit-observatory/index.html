Sources, privacy & limitations

This dashboard fetches an allowlisted aggregate feed from the Orbit app server. It contains numeric host and activity statistics, accessible wherever that app server is reachable. It contains no job names, conversation text, session IDs, process commands, hostnames, addresses or credentials. Do not expose Orbit publicly without access controls.

Collection is read-only. Alerts use CPU ≥90%, RAM ≥90%, disk ≥85%, saved job errors, jobs overdue by five minutes, service failures, unavailable sources, and browser acknowledgement age over 30 seconds. A fresh sample does not mean all sources are healthy. Pause freezes this dashboard only. Export downloads the current aggregate snapshot, not diagnostic logs. Workspace checkpoints do not stop the collector or restore history.
