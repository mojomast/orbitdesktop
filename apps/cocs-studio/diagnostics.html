Branch & Build Provenance

This lab runs an immutable source snapshot. Resolving a GitHub branch checks freshness; it does not silently replace the running engine or retarget the other tools.

Asset Workshop PR target: main (existing service). Lattice PR target: feat/fieldwork-plan. The embedded tools still manage their own sources. Do not mistake this selector for a synchronized branch switch.


World & Navigation Inspector
Actual Lattice Foundry navigation nodes and edges. Click twice on the map to select route endpoints, or use the node selectors. Yellow is the computed route. Red segments fail the engine's walkEdge probe.

Graph reachability is not full player traversal, roof access, vehicle clearance, or map publication approval. Map PR gates remain unchanged.


Vehicle Test Range
Real vehicle factories, attached-part inspection and articulated preview. This is a model bench, not driving or weapons physics.

Performance Lab
Measures real CPU simulation step durations in this browser using a fresh seeded match. Not GPU frame time or total game performance. Vehicle render counters are reported after loading a model.


Regression Scenario Runner
Runs source-backed deterministic replay, current route probes and vehicle reference checks. Results include scope and failures. These are diagnostics, not replacement Workshop publication gates.

Release Desk
Collects this lab's evidence into a review brief. Unknown and untested checks stay unknown. No push, PR creation, approval or merge is performed here.
