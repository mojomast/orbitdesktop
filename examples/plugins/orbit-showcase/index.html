What Orbit is

Orbit (\"Comet\" to its owner) is a single-owner desktop workspace built around a Hermes agent runtime. Native windows hold terminals, agents, browsers and reviewed built-in surfaces. Generated widgets like this one run in a sandboxed browser pane with no host token.

  • Spatial layout: windows have frames, monitors, pitch/yaw and an arc view.
  • Revisioned operations: every layout/appearance/plugin change is validated, checkpointed and acknowledged by the browser.
  • Agent-native: Hermes proposes changes; you approve. Checkpoints make rollbacks first-class.

Plugin lifecycle (this widget)

  • Publish: plugin_publish.py writes a content-addressed bundle under .runtime/apps.
  • Install (disabled): plugin_install with the emitted manifest.
  • Enable: plugin_enable opens/creates its window + browser pane.
  • Configure: primitive config map flows in via the URL fragment (#orbit-config=).
  • Update: republish, then plugin_update keeps identity/config; rollback via checkpoint.
  • Duplicate: stateless instances with fresh window/pane IDs.

State, checkpoints, recovery

  • Optimistic revision checks; 409 on conflict → read & adapt.
  • Every apply creates a checkpoint; history, checkpoint --label, restore.
  • Preview before large changes: preview then commit with its base revision.
  • Recovery console (/recovery) with registered-plugin activation hold.
  • Bulk ops: arrange_windows, reorder_windows, swap_panes, layout_panes, set_arc.

Execution & collaboration

  • Workbench: project tasks, checks, result artifacts (experimental, opt-in).
  • IRC: loopback ircd behind Orbit auth.
  • Colab: GPU/TPU runtimes via colab CLI.
  • Shared Chromium: co-browsing window at orbit://shared-browser.
  • Shared desktop: XFCE/X11 container (Tailscale 4346).
  • Xpra apps: Chromium, OpenOffice, Files, Terminal windows.

Data, documents & results

  • Document library: rich text + Excalidraw canvases with revisioned proposals.
  • Outputs: published files, aliases, pins, tags, draft refs.
  • Knowledge search: explicit source snapshots + exact citations.
  • Interactive results: A2UI v0.9 JSON/NDJSON import & edit.
  • Data workbench: CSV/JSON/Parquet SELECT via DuckDB, recipes.
  • Voice transcript: local mic transcription.
  • Run traces: redacted timing.
  • Browser copilot: disposable Chromium with staged actions.
  • MCP Apps: imported self-contained snapshots.

Sandbox & safety boundaries

  • This frame is sandboxed: no parent DOM, no Orbit tokens, no localStorage bridge.
  • Config arrives only via the URL fragment; never put secrets in config.
  • Network is allowed under the app CSP (no arbitrary localhost proxy).
  • Host-side changes require trusted source edits + tests + deploy.
  • Checkpoints restore layout/plugin registration, not private app state.
