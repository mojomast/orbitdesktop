# Hermes plays Doom / Jev arena

Private service integrated as an external-browser Orbit window; not a static sandbox plugin or a new privileged plugin bridge. Source: `extensions/hermes-doom/`. Deploy using `scripts/deploy_hermes_doom.py` on this installation after reviewing the bundle. Uses the trusted extension manager with explicit host-code trust, loopback 4462 and private Tailscale HTTPS 4362. No core service restart. Requires the installed dashboard Doom skill's ViZDoom/Pillow venv and shareware WAD; these are not redistributed in the bundle. Deployment config is owner-only under `.runtime/hermes-doom/`. This installer is local-specific, not a portable catalog release.

## Provenance / isolation

`engine.py` is adapted from `/home/mojo/.hermes/skills/gaming/doom-player/scripts/doom_watch_server.py`. Added pause and action-selection hooks, and accurate frozen-policy text. Native renderer, survival heuristic, spatial learner and bounded action executor come from that source. Uses a copied `audit/route_policy_v3.json` because the live dashboard currently runs an older spatial_v1 policy; incompatible old weights must not be silently imported. The original game on port 9988, skill source, WAD, learned policies and trajectories are never modified. Local mode uses frozen policy weights, epsilon zero and heuristic fallback; it is not a chat-model player and does not train or save. Historical learning counters in raw status refer to the copied policy, not Orbit performance.

## Jev research

Open-web discovery used WebXNG/SearXNG. Primary sources were fetched directly with curl because web_extract in this profile is search-only:

- https://typesafe.ai/blog/introducing-system-one-models-and-jev — Doom section explicitly describes structured text/data state, not images; notes a conventional bot could play better. Its claimed 10 queries/sec and cost are vendor demo claims, not our measurements. It promises a later walkthrough; the current docs index contains no Doom implementation.
- https://docs.typesafe.ai/api.md — POST `https://api.typesafe.ai/v1/systemone`, Bearer key, `jev-latest`, state/questions maps, Choice criteria and choice/probabilities/confidence response.
- https://docs.typesafe.ai/concepts/how-to-build-with-system-one.md — narrow decisions with surrounding code retaining control.

Our implementation is independently constructed against that documented API, not a copy of unpublished demo code. Each decision supplies only health/ammo, position/heading/map, bounded visible-object labels and five depth sectors. Choices contain only known action combinations supported by the actual engine buttons. Code validates choice, finite confidence, complete distribution, probability sum and argmax. Confidence below 0.65 uses local fallback; this threshold is provisional and uncalibrated. No commands generated by the provider are executed.

## Consent, cost, safety

Unlock with the existing Orbit host token. The service verifies it against Orbit; scoped session tokens live only in browser/service memory for four hours. Exact Host/Origin, bounded JSON, fixed static paths, CSP, no CORS and login throttling protect the API. Service never logs request bodies. Keys are supplied via the password input with explicit consent each run; no keys are read from existing secret stores or saved in localStorage/config/checkpoints. UI clears the key field on submission. Jev is OFF by default.

Maximum 100 calls, 120 seconds per run, four requests/sec and one request in flight. Fixed HTTPS endpoint, disabled redirects/proxies, five-second timeout and bounded response. Errors stop Jev, clear its key and return to local mode; low confidence also falls back. Pause cancels acceptance of in-flight results and clears the key. A request already transmitted cannot be recalled. Game simulation waits during inference, so this is not real-time performance parity with TypeSafe's demo. The viewer polls real JPEG frames; it is not a Doom simulation.

Closing a viewer does not stop the local game; Pause does. Jev expires even without a viewer while the engine runs. No paid/live inference was performed during development. Live API compatibility, latency/cost, decision quality and level-completion reliability remain unverified until an owner-authorized run. UI exposes calls, accepted choices, fallbacks, errors, last latency, confidence, token usage and remaining budget, but does not invent monetary savings.

## Recovery

`python3 scripts/extensions.py stop hermes-doom` stops this arena only. Tailscale route: `tailscale serve --https=4362 off`. Neither touches the dashboard game. Workspace checkpoints cover window metadata only, not engine state, credentials or external inference charges. The extension runner does not provide reboot supervision.
