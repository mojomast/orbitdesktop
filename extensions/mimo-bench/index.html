Measurement methodology and limits

All clocks run on the Orbit host with a monotonic timer. First output is time to the first nonempty content or reasoning delta, not HTTP headers or an empty role event. First answer excludes reasoning. Total time includes DNS, TLS, network, provider queuing, and the complete stream. Each request uses a fresh connection; no automatic retry.

Tokens/s = provider-reported completion tokens ÷ total request seconds, including reasoning tokens where the provider counts them. Missing usage remains unavailable; text length is never substituted for token counts. This is end-to-end throughput, not decode-only speed. P50/P95 use nearest-rank percentiles over successful requests only. Errors remain in the error-rate denominator. Small samples do not establish reliable tail latency.

Every measured call is included, including the first; provider caches may influence repeated prompts. Exact-match and JSON checks are narrow sanity checks, not a general intelligence benchmark. A length finish reason means the output hit its cap. Stop prevents queued requests from starting; in-flight calls can still finish and incur charges. Prices are not guessed. History survives service restarts; service startup after reboot is manual. Workspace checkpoints do not restore benchmark data or API spending.
